# Linked List, Stack, and Queue in C++

I implemented a linked list, stack, and queue in C++ as an object-oriented version of my earlier C data-structure work.

## What I implemented

- A linked-list class with its supporting operations.
- A stack class with push, pop, and related behaviour.
- A queue class with enqueue, dequeue, and related behaviour.
- Separate source, header, and test files.

The main goal was to practise encapsulation, class design, memory management, and automated verification of basic data structures.
