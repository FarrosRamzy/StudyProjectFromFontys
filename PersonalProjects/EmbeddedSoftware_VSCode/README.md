# Embedded Software Projects with PlatformIO

These projects were developed in Visual Studio Code with PlatformIO. I used Arduino-compatible boards to practise I2C and serial communication, register-level LED control, timing, and coordination between multiple microcontrollers.

## Projects

- **I2C Bus Programs** — sensor communication and Arduino master/slave exercises.
- **Rider LED** — independent blinking and LED sweep patterns controlled through bit manipulation.
- **Traffic Light System** — two Arduino controllers coordinating a traffic-light sequence through serial communication.
