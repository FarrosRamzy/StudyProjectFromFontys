# SysTick Assignment

In this assignment I explored three ways of using the ARM Cortex-M SysTick timer. I first polled the timer flag to create a delay, then enabled the SysTick interrupt, and finally used the custom timing code in a multi-LED application.

- [SysTick Polling Delay](./source_code/SYSTICK_A_assignment/)
- [SysTick Interrupt Blink](./source_code/SYSTICK_B_assignment/)
- [SysTick LED Pattern Controller](./source_code/SYSTICK_C_assignment/)

The configuration steps and test results are documented in [the SysTick report](./document/es_03_lab_03.pdf).
