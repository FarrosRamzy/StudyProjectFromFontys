# Interrupt-Driven Blink and Sweep Controller

I expanded the interrupt exercise into two coordinated behaviours: a single LED state and a row-of-LED sweep state. I used external interrupts, SysTick timing, and state enumerations to keep the behaviour organised.

## My work

I configured the required STM32 peripherals, wrote the user logic in C, tested the behaviour on the Nucleo-F303RE board, and used the assignment to practise reading the reference manual and manipulating peripheral registers.
