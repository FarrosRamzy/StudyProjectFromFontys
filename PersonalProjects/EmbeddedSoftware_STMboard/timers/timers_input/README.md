# Timer Input Capture

I configured an STM32 timer for input-related timing and handled timer interrupts to process measured values. This assignment helped me understand timer counters, prescalers, interrupt handling, and input capture concepts.

## My work

I configured the required STM32 peripherals, wrote the user logic in C, tested the behaviour on the Nucleo-F303RE board, and used the assignment to practise reading the reference manual and manipulating peripheral registers.
