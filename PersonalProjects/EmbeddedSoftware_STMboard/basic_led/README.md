# Basic STM32 LED Control

I configured the STM32 GPIO registers directly and used them to control the board LED. This small project introduced me to peripheral clock enabling, output-mode configuration, and register-level output control.

## My work

I configured the required STM32 peripherals, wrote the user logic in C, tested the behaviour on the Nucleo-F303RE board, and used the assignment to practise reading the reference manual and manipulating peripheral registers.
