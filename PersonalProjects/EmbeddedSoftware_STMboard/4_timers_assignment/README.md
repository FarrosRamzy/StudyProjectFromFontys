# STM32 General-Purpose Timer Assignments

I used these projects to move from basic digital timing to hardware-generated PWM and timer input capture.

The output exercises use TIM2 to control LED brightness and a hobby servo. The input exercise combines a timer-generated trigger with input capture to measure an HC-SR04 echo pulse.
