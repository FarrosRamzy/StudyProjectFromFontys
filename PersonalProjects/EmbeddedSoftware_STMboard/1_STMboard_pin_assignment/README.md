# GPIO and Pin Configuration Assignment

In this assignment I learned how to enable GPIO clocks, configure input and output modes, read button states, and write LED states directly through STM32 registers.

The folder contains three stages:

- [Basic LED Setup](./source_code/basic_led/) - direct configuration of the onboard LED pin.
- [Button-Controlled LED](./source_code/1_LED_button_a/) - a debounced button that toggles an external LED.
- [Button and LED Patterns](./source_code/1_LED_button_b/) - two buttons controlling a single LED and a row of animated LEDs.

The complete experiment and wiring are described in [the assignment report](./document/es_03_lab_01.pdf).
