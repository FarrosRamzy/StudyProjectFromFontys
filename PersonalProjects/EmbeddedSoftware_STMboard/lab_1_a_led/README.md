# Button-Controlled LED Patterns

I built a GPIO exercise with multiple LEDs and buttons. I configured input and output registers, read button states, and changed the active LED behaviour without relying entirely on high-level helper functions.

## My work

I configured the required STM32 peripherals, wrote the user logic in C, tested the behaviour on the Nucleo-F303RE board, and used the assignment to practise reading the reference manual and manipulating peripheral registers.
