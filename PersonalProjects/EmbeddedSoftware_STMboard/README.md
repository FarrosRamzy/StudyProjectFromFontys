# STM32 Register-Level Embedded Assignments

This folder contains embedded-software exercises I completed with an STM32 Nucleo-F303RE board and STM32CubeIDE. I focused on GPIO registers, SysTick, external interrupts, general-purpose timers, input capture, and PWM.

Each subfolder is a separate STM32 project. Together, they show my progression from basic output control to interrupt-driven and timer-based firmware.
