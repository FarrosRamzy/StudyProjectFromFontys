# STM32 Register-Level Embedded Software

This repository contains a series of embedded-software exercises I built on the STM32 Nucleo-F303RE board. I started with direct GPIO configuration, then moved into external interrupts, SysTick, PWM, timer input capture, ultrasonic distance measurement, and a PID-control prototype.

Most of the application logic is written close to the hardware using CMSIS register access. I used STM32CubeIDE for project generation, building, flashing, and debugging, while implementing the important peripheral configuration and runtime behavior myself.

## Hardware and tools

- STM32 Nucleo-F303RE
- STM32CubeIDE
- C and CMSIS register access
- LEDs, push buttons, resistors, and breadboard wiring
- Hobby servo for the PWM exercise
- HC-SR04 ultrasonic sensor for timer input capture
- Logic analyzer and serial terminal for verification
- MATLAB/Simulink for the feedback-control exercise

## Opening a project

Each source-code folder is an independent STM32CubeIDE project.

1. Open STM32CubeIDE.
2. Choose **File > Open Projects from File System**.
3. Select the project folder containing the `.project` and `.ioc` files.
4. Build the project.
5. Connect the Nucleo-F303RE through ST-LINK and run or debug the firmware.
6. Follow the related PDF report for the original wiring and experiment procedure.

## Repository notes

The `Debug/` folders contain generated build output and can be regenerated by STM32CubeIDE. The projects are academic hardware prototypes intended to demonstrate peripheral configuration and embedded-programming concepts rather than production firmware.
