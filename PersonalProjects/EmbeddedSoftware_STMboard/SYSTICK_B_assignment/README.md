# SysTick LED Timing — Interrupt

I extended the SysTick exercise by handling timing through the SysTick interrupt. I implemented the interrupt handler and bit-based LED control so the main loop did not need to manage every timing step directly.

## My work

I configured the required STM32 peripherals, wrote the user logic in C, tested the behaviour on the Nucleo-F303RE board, and used the assignment to practise reading the reference manual and manipulating peripheral registers.
