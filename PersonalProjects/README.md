# Personal Programming Projects

This repository contains personal and paired assignments I completed during my 2 years in ICT studies. The projects cover C, C++, C#, cybersecurity, and embedded software development with Arduino and STM32 boards.

Each folder includes a short README that explains what I built, what I learned, and which parts I implemented. Most of the projects are educational prototypes rather than production-ready applications.

## Project Areas

- **C Programming** — bit manipulation, arrays, pointers, data structures, file processing, parity, and unit testing.
- **C++ Programming** — object-oriented implementations of linked lists, stacks, and queues.
- **C# Applications** — desktop applications for course administration and sports-club device management.
- **Cybersecurity** — vulnerability research, security specialization work, and a personal body of knowledge.
- **Embedded Software with PlatformIO** — I2C communication, LED control, and a two-controller traffic-light system.
- **STM32 Embedded Software** — GPIO, SysTick, interrupts, timers, input capture, PWM, and register-level programming.

## Notes

Some folders contain generated build files from the original development tools. For a public portfolio repository, I would normally remove build output, IDE caches, and local configuration files before publishing.
