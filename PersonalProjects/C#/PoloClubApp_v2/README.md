# Polo Club Device Management App

I created this Windows Forms application to manage wearable devices used by members of a polo club. The system tracks devices, assigns them to users, and handles returns and invalid operations.

## What I implemented

- A club model for managing users and devices.
- Device types such as smartphones, smartwatches, and fitness trackers.
- An `IWearable` abstraction for shared wearable behaviour.
- Assignment and return workflows.
- Custom exceptions for invalid input and device-state errors.
- A graphical Windows Forms interface.

This project was mainly an exercise in object-oriented design. I used abstraction, inheritance, polymorphism, interfaces, and exception handling to keep the application behaviour organised.
