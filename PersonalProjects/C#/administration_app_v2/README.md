# Student Administration App

I built this Windows Forms application to manage students within a course and assign them to numbered project groups.

## What I implemented

- Student, course, and project-group models.
- A desktop form for entering and displaying data.
- Logic for assigning students to groups.
- Basic validation and application flow.

This was one of my earlier C# projects, so the design is intentionally simple. It helped me learn how classes can represent application data and how a Windows Forms interface can work with those classes.
