# C Programming Assignments

This folder contains three C assignments I completed to practise low-level data handling and algorithm design. I worked with logical and bitwise operations, pointers, arrays, file processing, parity checking, and unit tests.

## Projects

1. **Bit Handler** — performs bit-level transformations using return values and pointer-based functions.
2. **Animal Shelter** — manages animals in an array, including adding, removing, grouping, sorting, and testing.
3. **Encoder, Channeler, and Decoder** — simulates data transmission, corruption, parity detection, and recovery.
