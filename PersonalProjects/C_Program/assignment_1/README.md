# Bit Handler in C

I created this assignment to practise changing numerical data with bitwise and logical operations. The project contains two implementations: one returns the transformed value directly, while the other changes the value through a pointer.

## What I implemented

- Bit-level value manipulation in C.
- Separate return-based and pointer-based solutions.
- Small test programs to compare the two approaches.

This project helped me understand how values are represented and modified at the bit level, and how pointers can be used to update data outside a function.
