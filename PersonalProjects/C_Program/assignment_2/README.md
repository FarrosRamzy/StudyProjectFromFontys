# Animal Shelter Manager

I built this C program to practise arrays, pointers, sorting, and unit testing. The program stores animal records and provides basic operations for managing the shelter.

## What I implemented

- Adding and removing animals.
- Grouping animals by species.
- Sorting animals by name.
- Array and pointer-based data handling.
- A separate test program for the main operations.

The assignment gave me practical experience with structured data and with keeping program logic testable.
