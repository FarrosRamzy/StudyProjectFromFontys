# Project Documents

This folder contains the written project baseline and the hardware references I used while designing and implementing the system.

## Project documents

| Document | Purpose |
|---|---|
| `hospital_asset_tracker_project_plan.pdf` | Project context, assignment, approach, planning, risks, and goals |
| `hospital_asset_tracker_project_proposal.pdf` | Earlier project proposal and planned solution |
| `hospital_asset_tracker_project_system_requirements.pdf` | System boundary, requirements, interfaces, data rules, quality attributes, deployment, and acceptance criteria |
| `hospital_asset_tracker_project_use_cases.pdf` | Actors, requirements, use-case diagrams, detailed workflows, and traceability |
| `hospital_asset_tracker_project_design_document.pdf` | Architecture, subsystem design, data model, component design, behavior, communication, security, deployment, and testing |
| `tool_list_for_hospital_item_tracker.pdf` | Hardware and software tools considered for the project |

## Hardware references

| Document | Purpose |
|---|---|
| `EL-UHF-RMT01_datasheet.pdf` | RFID reader electrical and hardware reference |
| `EL-UHF-RMT01_protocol_documentation.pdf` | RFID reader serial command and response protocol |
| `ESP32-WROOM-32_datasheet.pdf` | ESP32 hardware, pins, electrical characteristics, and operating constraints |

## Suggested reading order

1. System Requirements
2. Requirements and Use Cases
3. System Design Document
4. Source-code READMEs
5. Hardware protocol and datasheets when working on the node

The project documents describe the intended system. The current implementation remains the final source of truth for exact file names, API behavior, and configuration details.
