# Asset Registration Frontend — Archived Iteration

I created this React and Vite application as the first dedicated interface for RFID asset registration and deregistration. It includes registration-node selection, scanned-tag handling, asset tables, search, sorting, pagination, API services, and WebSocket updates.

The asset workflow was later integrated with node management, movement decisions, users, authentication, and settings in the current Registration App:

[`../products/AssetTrackerRegistrationFrontEnd`](../products/AssetTrackerRegistrationFrontEnd/)

## Run this archived version

```bash
npm ci
npm run dev
```

This folder is kept as development history rather than the recommended application for demonstrations or deployment.
