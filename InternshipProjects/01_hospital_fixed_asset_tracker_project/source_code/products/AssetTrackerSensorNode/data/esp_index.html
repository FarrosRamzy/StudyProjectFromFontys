How to use

Fill in the Wi-Fi name (SSID), and click the connect button to connect your module to Wi-Fi network.

Tick the "This network has no password" checkbox if the Wi-Fi is an Open Network, or fill in the password textbox otherwise.

Click Refresh if your Wi-Fi Network name is not shown in the list.
