# Internship Project

This repository contains my internship project: a full-stack and embedded **Hospital Fixed-Asset Tracking System**.

I built the project as an end-to-end prototype that combines UHF RFID hardware, ESP32 sensor nodes, MQTT messaging, a FastAPI backend, PostgreSQL, and two React applications. The goal was to make movable hospital equipment easier to register, locate, monitor, and move through a controlled workflow.

## Project

| Project | Summary |
|---|---|
| [Hospital Fixed-Asset Tracking System](./01_hospital_fixed_asset_tracker_project/) | A checkpoint-based RFID system for asset registration, location monitoring, movement approval, node monitoring, alerts, and live updates. |

The current integrated implementation is stored under [`source_code/products`](./01_hospital_fixed_asset_tracker_project/source_code/products/). The project folder also includes requirements, use cases, design diagrams, hardware references, and test evidence.
